To-Do List: Break Down with Claude

An extension of my Artifact 2 to-do list. A Break down button asks Claude to split a big task into smaller steps. I review the suggestions and choose which ones to add. A small Python helper runs Claude Code, and plain code checks every answer before I see it.

The first real run failed with a blank error. I tracked it down by running Claude Code by hand: it wasn't logged in, and my helper was reading its error from the wrong place. Because Claude's job was kept small and the code checks everything around it, it was easy to tell whether a problem came from the model or from my code. I also learned to work around device limits by running everything in GitHub Codespaces.
