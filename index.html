An extension of my Artifact 2 to-do list. A Break Down button asks Claude to split a big task into smaller steps. I review the suggestions and choose which ones to add.

ARTIFACT 04 Built · User Feedback Received
▤

Internship Application Tracker

A web application that helps students organize internship applications. Users can add and edit applications, track their statuses and deadlines, search and filter results, and back up their information using JSON import and export. Applications are saved in the browser.

I developed my Internship Application Tracker using HTML, CSS, JavaScript, and Claude Code. Throughout the project, I worked on improving the application form, dashboard functionality, and overall design. This experience helped me strengthen my development, debugging, and testing skills while building a practical application for students.

After testing the application, I shared it with another student to get feedback on the overall design and functionality. The feedback was positive about the clean layout, with a suggestion to connect application dates to different statuses. I thought this was a useful idea that could make tracking applications easier in a future update.
